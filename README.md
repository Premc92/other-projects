# Data Analytics & Machine Learning — Supporting Projects

## Overview
A collection of exploratory Python projects covering web analytics, language detection, screen-time analysis, job recommendation and social-media analysis. These projects demonstrate broader analytical foundations that complement a credit-risk career portfolio.

## Projects
- Bounce-rate analysis
- Credit scoring and borrower segmentation (see the dedicated [Credit Score repository](https://github.com/Premc92/Credit-Score-based-segmentation))
- Instagram analysis
- Job recommendation system
- Language detection
- Screen-time analysis

## How this repository supports a Credit Risk Analyst profile
The strongest transferable capabilities are data cleaning, exploratory analysis, feature preparation, classification, text processing, visualisation and communicating findings. The dedicated credit-risk repositories should remain the primary portfolio projects.

## Improvement priorities
1. Add a short business question and data dictionary to each notebook.
2. Validate input types, missing values, duplicates and date formats.
3. Fit preprocessing steps only on training data; use pipelines for vectorisation and scaling.
4. Use stratified train/test splits for classification where suitable.
5. Avoid interpreting correlation as causation.
6. Label heuristic segments accurately; for example, session frequency is not the same as cohort-based customer retention.
7. Add reproducible setup instructions and concise conclusions.
8. Keep personal, confidential or licensed data out of the repository.

## Tools
Python, pandas, NumPy, scikit-learn, NLP libraries and visualisation libraries used in individual notebooks.

## Portfolio positioning
For Credit Risk Analyst applications, lead with the dedicated credit-scoring, fraud-detection and portfolio-risk work. Treat the remaining notebooks as supporting evidence of general analytical ability.
